# 步道乐跑 路线模拟 —— 使用说明

## 怎么用

1. 装好 Python 3.8 以上（安装时勾 **Add Python to PATH**）
2. 装好 MuMu 模拟器 12，在其中一个实例里装好下面两个 App：
   - **步道乐跑**
   - **FakeLocation**（需要 LSPosed 模块生效，能正常注入 mock 定位）
3. **双击 `run.bat`**

完了。脚本会自己找 MuMu 装在哪、自己找哪个实例装好了这两个 App（没开机就自己启动）、
自己认包名，然后按顺序做完：

1. 启动 FakeLocation 的路线模拟，打开**循环**
2. 打开步道乐跑，关掉成绩规则页 / 各种弹窗，进到乐跑 tab 的跑步页
3. 长按底部绿色按钮**起跑**

看到下面这行就成了：

```
[+] 搞定. FakeLocation 在跑, 步道乐跑已打开.
```

这时候模拟器里定位已经在沿校内循环路线走了，乐跑也在计时。**不用再手动操作。**

## 需要改配置的情况

`run.bat` 里有**两个可选变量**，99% 的情况留空就行：

| 变量 | 什么时候要设 |
|---|---|
| `MUMU_HOME` | MuMu 装得特别偏，自动扫描没找到。填安装根目录（含 `nx_main` 那一层） |
| `MUMU_INDEX` | 你有多个实例都装了 App，想指定用哪个。填实例号 |

改法就一行，去掉前面的 `REM`：

```bat
set "MUMU_HOME=D:\Program Files\Netease\MuMuPlayer-12.0"
set "MUMU_INDEX=1"
```

## 常见问题

| 现象 | 怎么办 |
|---|---|
| `Python not found` | 装 Python 时没勾 Add to PATH。重装一遍并勾上 |
| `没找到 MuMu 模拟器 12` | 手动设 `MUMU_HOME` |
| `实例 N 里没找到: FakeLocation` / `步道乐跑` | 那个实例里没装 App。装进去，或用 `MUMU_INDEX` 指定装好的那个 |
| `adb 连不上` | MuMu 设置 → 其他 → 开启 ADB 调试 |
| `没进到 FakeLocation 路线模拟页` | LSPosed 模块没启用，或者 FakeLocation 没授权。手动点一遍确认能用 |
| 没读到 mock 坐标 | LSPosed 模块没生效。模拟已经启动了，去模拟器里看一眼定位动没动 |
| **乐跑计时在走但里程一直 0.00** | **FakeLocation 停在暂停态**（路线模拟页左边那个按钮显示「继续」）。到模拟器里点一下「继续」，然后重跑 `run.bat` |
| **脚本把 FakeLocation 点了暂停** | 老版本的 bug，已彻底修好。原因是底层 adb 调用把「输出为空」误判成断线，**每个点击都执行了两遍**（点「启动模拟」= 启动后立刻暂停）。现在启动阶段只会点一次「启动模拟」 |
| **点了「继续」后马上又停了** | 同一个 bug（点两下），已修 |
| `没能打开步道乐跑到跑步页` | 最常见是 mock 定位没生效，乐跑首页卡在「获取当前位置失败」。确认第 2 步的 FakeLocation 能正常用 |
| `自动起跑没成功` | 乐跑已经开在跑步页了，手动长按底部绿色按钮起跑就行 |
| 重跑脚本后乐跑被暂停了 | 旧版本的问题，已修。现在脚本会先看按钮文字，显示「长按暂停」就绝不长按 |

## 目录里有啥

| 文件 | 说明 |
|---|---|
| `run.bat` | **双击这个** |
| `lepao_auto.py` | 主脚本 |
| `ocr.py` | 截图 OCR（只给可选的读屏功能用，主流程不依赖，不装中文语言包也能跑） |

| `_last_index.txt` | 自动生成，记住上次成功的实例号。想让它重新全扫就删掉 |
| `交接文档.md` | 给接手开发的人看的，包含所有实测细节和踩过的坑 |

## 说明

脚本负责：找 MuMu、找 App、启动路线模拟并循环、打开乐跑、起跑。

路线本身是校内循环路线，跑下去的里程和打卡点由乐跑自己计算，
脚本不参与里程判定和上传。
